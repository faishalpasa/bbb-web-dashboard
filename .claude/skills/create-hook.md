# Skill: create-hook

## Trigger

Use when asked to create or add a custom React hook.

## Steps

1. Determine page-local versus reusable placement.
2. Name it `use...` and define explicit option/return types.
3. Call typed services instead of raw Axios when data access is needed.
4. Handle cancellation/races and expose loading/error state where relevant.
5. Keep JSX and server-authoritative business rules out.
6. Add focused tests when the hook contains meaningful behavior.
